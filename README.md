# 🌟 LingoFlow · 随身英语学习工作台 (PWA)

手机优先的英语学习 Web App / PWA。明亮蓝白界面，支持添加到主屏幕；学习记录保存在当前设备，通过 JSON 备份迁移。当前样式要求 Safari 16.4+、Chrome 111+ 或 Firefox 128+。

---

## 📱 核心功能闭环

1. 💬 **AI 口语对练 (Oral Coach)**：
   - 多情景切换（日常闲聊、咖啡点单、求职面试、旅行入住、敏捷晨会、雅思口语）。
   - 语音/文字自由输入，真人级英语语音发音朗读。
   - **双轨纠错面板**：不仅顺畅对话，还能实时指出语法小漏洞，并提供外教级地道表达推荐。
   - **生词联动**：一键将口语地道表达收藏至生词本；支持在对话中引导练习今日生词。

2. 📖 **智能精读伴读 (Smart Reader)**：
   - 预置精选短文，支持一键粘贴任何外刊、新闻或美剧台词。
   - **点词即查**：使用免费基础英汉词库获取词义和音标，保留原文语境；需要深入讲解时再选择 AI 解析。
   - **长难句透视**：点击 🔬 图标，AI 剖析长难句主干、定语/状语从句拆解及核心语法要点。

3. 📇 **艾宾浩斯生词闪卡 (Flashcards & SRS)**：
   - 商务、计算机与编程、日常、旅行、学术、健康、媒体、科学环境 8 类词库，共 256 词，分入门、核心和进阶路线；附音标、搭配及双语例句，无需 API Key。
   - 分类随机练习优先未学词，点击收藏后才进入个人词库；重复词保留记忆进度与个人编辑。支持看词回忆和听音拼写，切页或刷新可恢复本次练习。
   - 分步间隔复习：根据“重来 / 困难 / 掌握”调整下次复习时间；这是项目自定义调度规则。
   - 3D 翻转卡片沉浸交互，结合语境例句记忆。
   - **AI 语境测验**：根据你的生词本一键生成 3 道情境填空题，巩固记忆。

4. ⚙️ **个人自用配置 (Settings)**：
   - 支持 DeepSeek（推荐·极高性价比）、硅基流动、OpenAI、月之暗面等所有兼容 OpenAI 接口的模型。
   - Key 与历史记录保存在浏览器本地；对话内容会直接发送给你选择的 AI 服务商处理。
   - 支持 **JSON 一键导出与导入备份**，通过文件在设备间手动迁移学习记录。

5. 🗓️ **今日计划与课程闭环**：
   - 每日任务固定目标词卡与课文，实际练习后自动更新完成状态；手动勾选单独记录。
   - 学习时长只计入页面可见且近期有操作的时间；历史估计时长保留并注明。
   - 新概念错题分日复测，支持用本课词进入口语表达练习。
   - 生产构建预缓存应用页面；本课离线包包括课文、字幕与原版音频。AI 功能仍需联网及 API Key。

本轮改进与验收范围见 [2026-10-08 实施记录](docs/IMPLEMENTATION_2026-10-08.md)。历史诊断文档记录当时版本，不代表当前状态。

6. 🧩 **语法实验室**：
   - 五大句型骨架与 there be，配套成分标注、易错点和练习。
   - 8 节句子拓展课程：方式地点时间、状态与方式、频率、介词短语、定语、疑问否定、谓语时态和从句。
   - 互动扩句实时显示语序与成分；8 节共 64 道应用、成分、改错和语序题，配套解析、自由造句与自评，无需 API Key。
   - 手机使用可折叠章节目录，桌面采用目录与讲解双栏。详见 [UI 与语法更新](docs/UI_GRAMMAR_2026-09-30.md)。

## 查词、可靠性与发布

全局词典包含 59,136 个英汉词条，在当前学习页面上打开弹层；课程、文章和手动加词共用基础查词。下载完整词库后可离线查询。新增 6,827 条有出处的音标，缺失项明确显示；数据来源与构建方式见 [词典说明](docs/DICTIONARY.md)。

阅读有理解题与 30 秒复述记录，口语支持失败重试和隔日纠错回忆。课程采用首答成绩判断独立回忆，重试不会抬高首次分数；原课程录音保留。

新会话、阅读收获与口语纠错使用 IndexedDB，其他已有记录保留 localStorage 接口。备份覆盖两类存储；写入失败保留内容并提示重试，连接配置默认不导入。

```bash
npm ci
npm run validate
npm run test:e2e
npm run deploy
```

`validate` 运行测试、零告警 lint 和构建，并记录源码及构建指纹；部署必须匹配检查记录。桌面和手机尺寸的浏览器回归与 CI 模板已准备，当前 GitHub 凭据不允许新增工作流，启用方式见 [CI 说明](docs/ci/README.md)。`dist/version.json` 可核对线上部署对应的源码提交。

## 🚀 极速上手：本地电脑运行并在手机上体验

### 1. 启动本地开发服务器
在本项目根目录下运行：
```bash
npm run dev -- --host
```
终端会输出两个地址：
- 本地地址：`http://localhost:5173`
- 网络地址：`http://192.168.x.x:5173` （局域网 IP）

### 2. 手机直接访问
只要你的手机和电脑连接同一个 Wi-Fi，在手机浏览器中打开这个 `http://192.168.x.x:5173`，即可立即使用！

## 📲 如何添加到手机主屏幕（PWA）

### 🍎 iPhone (苹果 iOS)
1. 用自带的 **Safari 浏览器** 打开你的网址。
2. 点击屏幕下方的 **分享按钮**（正方形带向上箭头 📤）。
3. 往下滑动菜单，点击 **“添加到主屏幕” (Add to Home Screen)** ➕。
4. 点击右上角“添加”，桌面即出现独立图标，点开全屏运行无任何浏览器边框。

### 🤖 Android (安卓手机)
1. 用 **Chrome 或 Edge 浏览器** 打开你的网址。
2. 点击右上角 **三个点菜单 ⋮**。
3. 点击 **“安装应用”** 或 **“添加到主屏幕”** 即可。
