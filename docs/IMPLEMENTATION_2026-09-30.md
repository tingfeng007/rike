# 2026-09-30 优化实施记录

本轮按可靠性、每日学习闭环、功能体验的顺序实施。保留本地数据架构和课程原版音频，不改变备份格式中的已有学习记录。变更保存在当前工作树，尚未部署。

## 第一轮：可靠性与学习结果

- 文章、词条和学习记录写入失败时明确返回失败；文章删除失败保留笔记与阅读位置。学习事件失败回退统计，评分失败保留当前卡片。
- 精读查词采用可取消的最新请求，只允许当前词对应的响应更新弹层；关闭弹层、换词与卸载取消旧请求。
- 口语中使用目标词记录为使用次数，不自动延长 SRS 间隔。
- 课程掌握度根据听写、练习与测验得分计算；仅查看单词或完成零分练习不产生虚假的掌握度。
- 新增共享活动计时器，只统计前台且近期有操作的时间，每段时间只消费一次；历史估计值保留并标注。手动勾选计划单独记录，不冒充模块练习。

## 第二轮：今日计划与目标传递

- 每天冻结目标，任务不会因复习完后到期队列变短而消失。
- 计划中的词卡与错题 ID 传递到练习页面，优先处理最早到期词；重来卡片继续出现在当前组。
- 实际完成目标后首页自动更新；继续下一组使用剩余到期词，不重复固定计划的词卡。
- 恢复未完成试卷、指定课文与文章；课程完成后优先继续未完成或下一课。
- 未配置 API Key 时每日计划不安排口语 AI 任务。修改每日时长明确重新生成任务。

## 第三轮：功能与体验

- 生产构建生成带版本指纹的 Service Worker，预缓存所有页面 JS/CSS，支持离线打开从未访问的学习模块。修复 Vary: Origin 导致预缓存模块无法匹配的问题，保留用户下载的音频与 TTS 缓存。
- “下载本课离线包”保存课文、字幕与原版音频，只有完整检查通过后才显示就绪；切课和卸载取消下载。
- 课程错题第一次答对后一天复测，第二次答对后三天复测，第三次答对后移除；间隔内重复点击不能提前通过。
- 精读专注模式隐藏文库与工具区，字号持久化；点词与词卡支持键盘操作，弹窗支持焦点循环与 Escape，手机允许缩放。
- 课程增加“回今日计划”和“用本课词练表达”；口语停止并发送等待识别结束，使用最新识别文本。
- 新学习记录积累后提示导出备份；设置页明确记录“发起导出”，不假定浏览器已成功保存文件。
- 拆分示例语料、请求控制、复习队列和计时服务，降低核心存储文件体积。README 修正 SRS 与设备间迁移说明。
