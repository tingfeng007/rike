# UI 与语法实验室更新

## 实际改动

- 应用不再把桌面限制为手机宽度：最大宽度 1040px，手机保持全宽，底部导航内容居中。
- 首页采用桌面任务 / 学习回看双栏、手机单栏。任务标题和说明可完整换行，开始为主要动作，手动完成明确标示；增加直接进入语法的入口。
- 公共标题区允许标题与学习状态换行，增加正文行距和触摸区域；移除到期徽章的持续闪烁。
- 语法课程分为“句子拓展 / 基本骨架 / 巩固练习 / AI 拆句”。桌面固定目录，手机使用章节选择器并按需展开全部目录。
- 8 节新课程，每节包含 4 条详细讲解、2–3 个逐成分例句、易错对比及 2 道应用练习，共 16 道。旧五大句型练习继续保留。
- 互动扩句支持频率、方式、地点、时间的可选组合与时间前置。结果有成分标签；“只看主干”清除补充信息。
- 纠正“宾语只靠删除测试判断”的过度简化；说明 put 的地点补足语、频率副词位置，以及状态形容词与方式副词的区别。
- 新题目使用稳定 ID、打乱选项位置，复用既有进度和错题数据格式。综合练习包含骨架和应用题，错题复习纳入新章节。
- 发布期间遇到已移除的资源时，Service Worker 尝试原缓存副本；新版 worker 等旧页面退出后启用，避免切断学习中的旧模块。

## 教学边界

句末“方式 → 地点 → 时间”是常见中性顺序，不是固定公式。频率、副词强调位置、必需补足语和从句需分别分析。内置句型判定仍是有限词表的辅助工具，复杂句可用 AI 拆句。例句为自编；常用词序与形容词 / 副词规则参考页面内的 Cambridge 链接。
