# 🕵️ LingoFlow 普通小白用户视角·全流程体验走查与挑刺报告 (UX Friction Audit)

> **走查角色设定**：一位英语基础普通、想利用碎片时间练口语和背单词的普通上班族。  
> **核心特征**：**不是程序员，完全不知道什么叫 API Key、Base URL、Model、Token 或 JSON**；使用 iPhone 17 (iOS Safari) 和安卓手机操作。  
> **归档位置**：`docs/UX_FRICTION_AUDIT.md`

---

## 🧭 一、上手流程走查：第一次打开软件，能否一眼看懂？

### 1. 首页第一印象与心理预期
- **用户第一眼看到的内容**：
  - 界面打开在【口语对练】Tab；
  - 顶部写着“日常闲聊 Oral Coach - 像老朋友一样随心聊聊今天的心情与生活趣事”；
  - 中间有一句外教 Echo 的英文问候：*“Hey there! How's your day treating you so far?”*；
  - 底下有一排情景药丸切换（咖啡馆、英文求职面试、机场旅行...）；
  - 最底下是一个麦克风按钮和一个写着“用英语回复或点麦克风说话...”的输入框。
- **直观体感**：页面设计非常清新现代，像一个高档外教聊天工具，第一眼感觉很舒服。

---

### 2. 致命硬伤！发第一句话立刻遭遇“大红脸”报错（劝退指数：★★★★★）

- **真实场景还原**：
  小白用户很高兴，看到外教热情的问候，顺手点击了外教下方系统推荐的蓝色快捷回复气泡：`💭 Not bad! Just finished my work and relaxing.`，然后点了发送。
- **系统给出的反应**：
  代码定位：`src/services/ai.js` 第 47 行：
  ```javascript
  if (!apiKey) {
    throw new Error('未配置 API Key，请先进入“设置”页面填入您的 API Key');
  }
  ```
  聊天窗口立刻弹出一个刺眼的大红框：
  > ❌ **Oops! 未配置 API Key，请先进入“设置”页面填入您的 API Key**  
  > *中文大意：请求出现错误，请检查设置中的 API Key 或网络状况。*

- **小白用户的内心独白**：
  > “啊？什么情况？什么是 API Key？我是不是被骗了？这个软件是坏的吗？为什么点一句话就报错？”

- **问题本质**：
  整个首页**完全没有任何新手向导（Onboarding）**，也没有在第一次打开时给予醒目的提示横幅。而是静悄悄地让小白用户直接去踩这个地雷，造成极其强烈的挫败感。

---

### 3. 设置页面的“极客黑话墙”（劝退指数：★★★★☆）

- **真实场景还原**：
  小白用户被报错逼着点进了底部的【设置】页面，原本以为会有一个简单的注册或扫码，结果迎面扑来一整套**程序员专属的配置表单**：
  1. **选择 AI 服务商 (支持 OpenAI 兼容协议)**：下拉选项里是 DeepSeek、硅基流动、OpenAI、月之暗面、OpenRouter... 小白完全不知道谁是谁，谁便宜谁好用。
  2. **API Key (保存在手机本地浏览器中，绝不上报服务器) \***：输入框 placeholder 是 `sk-...`，小白不知道去哪找。虽然旁边有个“获取 Key”的小链接，点开是开发者开放平台的注册、充值和实名认证，劝退率高达 90%！
  3. **API 基础路径 (Base URL)**：填着 `https://api.deepseek.com`。小白心里直打鼓：“这是什么网址？我要不要改？改错会不会彻底不能用了？”
  4. **调用模型名称 (Model)**：填着 `deepseek-chat`。小白完全不知道这是什么意思。

- **问题本质**：
  当前设置项是用**工程师的思维**排布的（把所有底层变量直接裸露在用户脸上），没有进行“小白模式”与“极客模式”的分层设计。

## 🖐️ 二、操作繁琐度走查：核心路径是否顺手？

### 1. 口语对练：说完一句话竟然需要“足足点击 3 次”
- **现状操作链路**：
  `点击麦克风开始录音` ➔ `说完话点击“完成录音”` ➔ `转录文字进入输入框后，还得再去点击右侧的“小飞机发送”按钮`。
- **吐槽与卡点**：
  在微信或主流语音输入工具中，用户习惯的是“说话 ➔ 自动发出去”。
  现在用户录完音，文字被静止放在输入框里，用户必须抬起大拇指，再次对准屏幕最右边那个直径仅 24px 的发送按钮点一下才能发出去。每聊一轮就要点 3 次，手指极其疲劳。

---

### 2. 精读伴读：查词弹窗不自动关闭，阅读心流被频繁打断
- **现状操作链路**：
  在读外刊时，看到一个生词点一下 ➔ 底部弹出大半屏的词汇卡片 ➔ 点击最下方的【存入生词本】 ➔ 按钮变成【已存入生词本】。
- **吐槽与卡点**：
  存入成功后，这个大卡片**死死盖在文章上面，不会自动收起**！
  而且该弹窗**不支持手指下滑手势退出**。用户必须把大拇指伸到屏幕右上角，费力地去找那个小小的 `X` 叉叉按钮点一下，才能回到文章继续看下一行。
  如果读一段话有 3 个生词，就要重复 3 次“点词 ➔ 存词 ➔ 找右上角叉叉关闭”，阅读体验支离破碎。

---

### 3. 生词复习：无法直接看到生词属于哪篇文章
- **现状操作链路**：
  在【生词闪卡】背单词时，虽然能看到例句，但如果想重温这篇外刊的上下文，界面上没有任何**“回看原文出处”**的链接，两个模块之间像两个独立的孤岛，没有串联成沉浸感。

## 🏆 四、体验顺滑度改进建议：Top 3 最反人类交互卡点

```
┌────────────────────────────────────────────────────────────────────────┐
│                        【三大核心体验卡点与改造方案】                     │
├────────────────────────────────────────────────────────────────────────┤
│ 🔴 卡点 1：首次打开无指引，首发消息直接大红字报错                        │
│ 改造方案：首页增加【新手 30 秒极速开启】卡片 + 设置页隐藏极客参数       │
├────────────────────────────────────────────────────────────────────────┤
│ 🔴 卡点 2：语音对练“说话-停止-发送”三步操作极其累手                      │
│ 改造方案：录音条提供【点我立即发送】大按钮，或引入停止说话自动发送机制   │
├────────────────────────────────────────────────────────────────────────┤
│ 🔴 卡点 3：精读查词弹窗无手势下滑退出，加词后不自动收起                  │
│ 改造方案：支持手指任意下滑退出 + 存词后轻量打勾并在 0.8 秒后自动收起     │
└────────────────────────────────────────────────────────────────────────┘
```

---

### 🔴 Top 1（致命门槛）：新手首次打开缺乏引导，首条消息直接大红字报错

#### 1. 痛点分析
没有 API Key 是无法使用 AI 能力的，但软件却在首页装作“万事俱备”，直接引导用户发送消息，然后把大红字错误直接甩在用户脸上。去到设置页后，又被 Base URL、OpenAI 协议等技术名词彻底吓跑。

#### 2. 丝滑改造方案
1. **首页智能新手引导卡**：
   当检测到本地没有配置 API Key 时，口语对练页面的输入框上方展示一张设计精致、温和的卡片：
   > **👋 欢迎来到 LingoFlow！开启你的随身外教**  
   > *只需填入你的专属 AI 密钥（我们绝不存储你的对话，隐私 100% 留在你的手机里，几分钱畅聊数百句！）*  
   > 🔘 **[立即填入 Key 开启体验]**　或　**[一分钟免费获取 Key 教程]**
2. **设置页黑话折叠（小白化改造）**：
   - 绝大多数人只会用默认的 DeepSeek。
   - 默认**隐藏 Base URL 和 Model 输入框**（收进一个灰色的“高级极客选项（小白无需修改）”折叠菜单里）。
   - 整个页面第一视觉只留下：**一个清晰的【填入你的 API Key】输入框** + 一个大号绿色【一键测试并保存】按钮！小白 5 秒钟就能搞懂。

---

### 🔴 Top 2（操作累手）：口语对练“点开录音 ➔ 点完成录音 ➔ 再点发送”三步累死大拇指

#### 1. 痛点分析
口语对练的核心是“对话的节奏感”。目前录完音后，文字呆板地躺在文本框里，用户还必须用大拇指去够最右边的发送小图标，无法一气呵成。

#### 2. 丝滑改造方案
1. **录音浮层一键合并发送**：
   在正在录音的粉红色提示条右侧，把那个不起眼的“完成录音”文字，改成一个显眼绿色的 **“🚀 说完了，立即发送”** 胶囊大按钮。用户说完轻点一下，录音停止并自动把话发给外教，直接省去第 3 步！
2. **静音自动发送机制（可选开关）**：
   增加智能停顿检测：当用户说完话停顿超过 1.5 秒，系统自动倒计时“3、2、1”自动发送，用户两只手甚至都不需要碰屏幕，就能跟外教自然顺畅地持续聊下去！

---

### 🔴 Top 3（心流打断）：精读查词弹窗无法手势下滑，存入生词后不自动收起

#### 1. 痛点分析
外刊精读需要沉浸。现在的词汇半模态卡片覆盖在页面上，点击“存入生词本”后依然霸占全屏，用户必须抬头精准点右上角的小叉叉。如果一段有几个生词，阅读节奏完全被毁掉。

#### 2. 丝滑改造方案
1. **存入后优雅自动收起（Auto-dismiss with delight）**：
   当用户点击【一键存入生词本】后，按钮瞬间变成绿色的【已存入生词本并开启复习 ✨】，并伴随轻微的震动/音效；**停留 0.8 秒让用户看清成功状态后，弹窗优雅地向下滑动收起**，自动将视野还给文章，用户可以无缝继续看下一句话！
2. **支持全手势下拉关闭（Swipe down to dismiss）**：
   在弹窗顶部加上一根灰色小拉手横条（Grabber），用户用手指在卡片任意位置往下一划，卡片立刻跟手滑下退出，彻底解放大拇指。
