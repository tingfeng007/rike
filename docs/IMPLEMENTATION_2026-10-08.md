# 全面优化实施记录 · 2026-10-08

本次按全量审查的问题清单修复教学逻辑、学习连续性、数据可靠性与页面体验，并补齐发布检查。视觉沿用明亮蓝白与 iOS 分组布局，没有使用 frontend-design skill。

## 已实施的功能与体验改进

| 审查问题 | 当前行为 |
|---|---|
| F01 课程末题与重复计分 | 按题 ID 记录首答；末题进入完成页，保存失败保留作答；完成事件只计一次。 |
| F02 句型误判 | 不再根据单词数量硬猜句型；名词短语、状语与介词宾语分别处理；有歧义时明确返回无法确定。 |
| F03 听写漏否定词仍正确 | 大小写、标点可容忍；否定词、数字及内容词缺失或替换会判错，错题复盘沿用相同规则。 |
| F04 全量恢复遗漏 | 备份 v4 包含词库、批注、课程、试卷、语法进度、阅读证据、学习会话、口语纠错及词典历史；异步数据等待事务提交。可重新下载的缓存不作为学习记录导出。 |
| F05 空备份混入示例 | 导入读取真实持久化数据；空备份保持为空。收藏第一个真实词也不会顺带收录示例词。 |
| F06 保存失败被覆盖 | 按数据域保留错误，界面显示待保存提醒；草稿与答案保留；写入成功后才显示保存成功。 |
| F07 域名变化沿用旧 Key | 默认不导入 AI 连接；单独选择并预览连接变更；换服务域名不继承旧密钥。 |
| 基础查词不一致 | 精读、课程、手动加词共用基础词典，不需要 Key；AI 语境扩展由用户明确触发。 |
| 查词中断学习 | 词典成为全局弹层，保留当前页面；hash 链接和浏览器返回支持课程、文章、场景及生词/语法子页。 |
| 口语草稿及重试 | 场景草稿、待完成消息可恢复；失败重试复用消息 ID，排除本地错误提示，不重复加入用户句；纠错句进入隔日回忆队列。 |
| 请求竞态和等待 | 拆句换内容、切页或关闭时取消旧请求；目录、下载和云语音都有等待上限，下载可取消。 |
| 课程复习到期 | 课程到期回忆进入今日计划；明确完成回忆后续期，同一练习不能连续重复提交。保留原课程音频，并连接原字幕。 |
| 分类词卡自动入库 | 分类生成临时牌组；用户主动收藏单词或本组后才进入个人复习。支持等级、每组数量与优先抽取未学词。 |
| 首屏和页面层级 | 手机词卡顶部准备区压缩、设置折叠；首页只突出一项继续任务，其他任务随后显示；桌面继续卡与今日队列并排。精读文库默认收起；设置分为数据、声音、AI、离线四组。 |
| 无障碍 | 闪卡非活动面 inert；设置输入绑定标签、图标有名称；弹层具名、焦点限制与返回，背景不可交互；文章逐词支持方向键、Home、End。 |

## 内容与学习闭环

- 8 个分类共 **256 个词**，每类 32 词，分为入门 8、核心 16、进阶 8，包含音标、中英文例句和常见搭配。
- 8 节语法共 **64 道题**：成分识别、结构应用、改错及排序。讲解区支持逐层扩句、章节前后导航、自由造句与自评；自评记录不包装为正确性认证。
- 8 篇内置阅读各有 2 道理解题，配合 30 秒英文复述和持久化阅读证据；导入文章可选择 AI 生成理解题。
- 闪卡增加听音拼写，检查前隐藏考察词、音标与例句；测验不提前展示目标词。微故事转存保留中文与目标词。
- 词典保持 59,136 条英汉词；用固定版本、MIT 授权的 ipa-dict 为原先无音标的 **6,827** 条词补充音标并标记来源。仍有 **4,503** 条缺音标，界面如实提示；不承诺完整中文反查。

## 存储、离线与工程

新学习会话、阅读证据与口语纠错使用 IndexedDB，兼容旧版 localStorage。跨标签同步通过三方合并与冲突副本减少旧快照覆盖；导入新增数据失败会回滚。设置提供存储估算、持久存储申请及课程、词典、云语音缓存管理。词典缓存损坏时联网自愈，离线包检查实际分片；云语音缓存有容量和 LRU 上限。Service Worker 只清理本应用缓存，不重复存储词典分片。

新增 PNG 192/512 与 Apple Touch 图标。请求、会话、备份合并、课程计分和词典历史提取为共享服务或 hook。拆分公共依赖后，本次构建的首屏 JS 约 **112.8 kB gzip**，审查时约 117.8 kB；这是构建体积测量，不代表真机 LCP/INP。

发布使用 `npm run validate` 运行单元测试、零警告静态检查和生产构建，并绑定同一源提交及源码/产物指纹；部署拒绝未检查或检查后修改的产物。`version.json` 记录源提交、数据版本与构建时间。已编写桌面、390×844 手机浏览器流程测试及 GitHub Actions 模板；终端凭据缺少 workflow scope，GitHub 插件也拒绝写入，因此自动 CI 尚未启用，模板保存在 `docs/ci/learning-flow.yml`。依赖扫描已修复当前报告项，`npm audit` 返回 0。
