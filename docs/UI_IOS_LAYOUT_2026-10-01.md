# LingoFlow 页面排版更新

按用户提出的年轻化、更多 iOS 风格要求，重新设计页面结构，继续不使用 frontend-design skill。

## 页面变化

- 首页以「下一步学习」为主卡片，显示真实任务与完成进度；模块入口使用四张独立卡片，今日目标改为分组列表。
- 时长选择、推迟任务、手动完成、每周回看和示例内容提示仍保留，次要操作按需展开。
- 手机使用圆角浮动导航，桌面使用侧边导航；首页在宽屏使用分栏布局。
- 精读页采用大标题和图标操作，将字号、整篇朗读、完成标记与换文放入阅读工具展开区。
- 闪卡页将次要功能收进菜单，增加可直接点击的分类入口，保留随机词卡、音标、中文释义、例句和记忆评分。
- 新概念首页采用书封面与课程卡片，宽屏课程目录采用双列布局，听读和原始课程音频流程保持原样。
- 语法与设置使用一致的圆角分组容器、文字层级和留白；保留减少动态效果的系统偏好。

## 检查

- 135 项现有测试通过，包括所有主要页面的首次渲染。
- 构建通过，lint 无错误；现有标签关联和列表键等警告仍存在。
- 在浏览器检查 375/390 像素手机首页、精读阅读工具展开、分类闪卡与翻面、更多菜单和生词清单、口语、课程、语法及设置；1440 像素检查桌面导航与首页分栏。
- 发布后核对 GitHub Pages 状态和入口资源，并检查真实线上页面。
